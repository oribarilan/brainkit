# US-wl-8: Copilot CLI agents

**Parent:** [US-work-life-split](./US-work-life-split.md)
**Depends on:** US-wl-3
**Unblocks:** nothing

## Goal

Generate three `.agent.md` files for Copilot CLI, each with a scoped system prompt matching the OpenCode agent equivalents.

## Changes

### `cli/copilot.ts`

Update the Copilot launcher to install three agent files in the vault:

- `bk.agent.md` — system prompt with `scope: "all"`
- `work.agent.md` — system prompt with `scope: "work"`
- `life.agent.md` — system prompt with `scope: "life"`

Each file uses the `.agent.md` format that Copilot CLI recognizes. The system prompt content is generated by `buildSystemPrompt(config, vaultPath, { scope, mode: "cli" })`.

### Agent file format

```markdown
---
name: work
description: Work sub-vault only — focused work sessions, performance reviews
---

<system prompt content generated by buildSystemPrompt with scope: "work">
```

### Generation timing

Agent files are generated during `installCopilotHooks()` (or equivalent setup function). They regenerate when:

- Vault config changes
- The CLI launcher runs setup

### Existing agents

If there are existing Copilot agent files (e.g., for Thinker/Consultant/Librarian), decide whether to keep them alongside the scope agents or replace them.

## Tests

File: `cli/__tests__/copilot.test.ts` (extend existing)
